# M-002 / M-003: 画像・動画設定・ウィンドウ可視性 E2Eテスト仕様書

## テスト対象
右クリックメニューからの画像・動画設定（中央・背景）と、ウィンドウが行方不明にならないことの保証

## テストケース

### TC-101: 中央に画像を設定
- **前提条件**: アプリ起動済み・中央画像未設定
- **手順**: 時計上で右クリック → 「中央に画像・動画を設定…」→ 画像ファイルを選択
- **期待結果**: 時計中央の円内に画像が円形に切り抜かれて表示される

### TC-102: 背景に画像を設定
- **前提条件**: アプリ起動済み・背景画像未設定
- **手順**: 右クリック → 「背景に画像・動画を設定…」→ 画像ファイルを選択
- **期待結果**: ウィンドウ全体の背景が選択画像になる（縦横比を保ち中央を基準に敷き詰め）

### TC-103: 設定の永続化
- **前提条件**: TC-101 / TC-102 実施済み
- **手順**: アプリを終了し再起動
- **期待結果**: 中央画像・背景画像が再起動前と同じ状態で復元される

### TC-104: 中央画像の解除
- **前提条件**: 中央画像設定済み
- **手順**: 右クリック → 「中央を解除」
- **期待結果**: 中央の画像が消え、既定の見た目に戻る

### TC-105: 背景画像の解除
- **前提条件**: 背景画像設定済み
- **手順**: 右クリック → 「背景を解除」
- **期待結果**: 背景が既定の羊皮紙テクスチャに戻る

### TC-106: 未設定時の解除メニュー
- **前提条件**: 画像未設定
- **手順**: 右クリックしてメニューを確認
- **期待結果**: 「中央を解除」「背景を解除」が選択できない状態（グレーアウト）

### TC-107: キャンセル時に変更されない
- **前提条件**: 任意
- **手順**: 「中央に画像・動画を設定…」→ ファイル選択ダイアログをキャンセル
- **期待結果**: 表示は変化せず、設定も書き換わらない

### TC-107b: 中央に動画を設定
- **前提条件**: アプリ起動済み
- **手順**: 右クリック → 「中央に画像・動画を設定…」→ mp4 ファイルを選択
- **期待結果**: 中央の円内で動画が自動再生され、ループする（音は出ない）

### TC-107c: 背景に動画を設定
- **前提条件**: アプリ起動済み
- **手順**: 右クリック → 「背景に画像・動画を設定…」→ mp4 ファイルを選択
- **期待結果**: 背景全体で動画が自動再生され、ループする

### TC-108: フルスクリーン抑止
- **前提条件**: アプリ起動済み
- **手順**: ウィンドウ左上の緑ボタンを確認・クリックを試みる
- **期待結果**: フルスクリーンにならない（別デスクトップへ移動しない）

### TC-109: 多重起動時のウィンドウ復帰
- **前提条件**: アプリ起動済みでウィンドウが非表示（✕ を押した後）
- **手順**: Finder / Launchpad から未来時計を再度起動
- **期待結果**: 新しいプロセスは起動せず、既存ウィンドウが表示され最前面になる

### TC-110: 起動時のフルスクリーン自己修復
- **前提条件**: 何らかの理由でフルスクリーン状態が復元される状況
- **手順**: アプリを起動
- **期待結果**: 自動的にフルスクリーンが解除され、通常のデスクトップ上に表示される
